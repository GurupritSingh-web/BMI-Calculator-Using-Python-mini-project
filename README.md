BMI Calculator
Its a simple BMI (Body Mass Index) Calculator built using Python. The program takes the user's name, weight in pounds, and height in inches, calculates their BMI, and provides a BMI-based result.

#Features

* Takes the user's name as input
* Accepts weight in pounds
* Accepts height in inches
* Calculates BMI using the imperial BMI formula
* Displays the calculated BMI
* Provides a BMI category based on the result

BMI Formula

For weight in pounds and height in inches:
BMI = (weight in pounds x 703) / (height in inches x height in inches)


## How It Works

1. The user enters their weight in pounds.
2. The user enters their height in inches.
3. The user enters their name.
4. The program calculates BMI using the imperial formula.
5. The BMI value is displayed.
6. The program evaluates the BMI using conditional statements and displays the corresponding result.
